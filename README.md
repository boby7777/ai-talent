# 個人 AI 能力評估表單

依《AI產業人才認定指引》「AI產業人才賦能範本教材」中的紙本問卷與計分公式製作的網頁版自評工具，供內部測試使用。

CC-BY 數位發展部數位產業署、財團法人人工智慧科技基金會（ADI、AIF）

## 使用方式

純前端靜態網頁，不需安裝、不需伺服器，雙擊 `index.html` 或用任意瀏覽器開啟即可填答。

所有運算皆在瀏覽器本機記憶體完成，不會上傳或儲存任何填答內容；重新整理頁面即會清空重來。

## 問卷流程

1. 基本資料（姓名／部門／職稱／主要職能）
2. AI 能力自評：常用工具多選、工具使用說明（開放文字，不計分）、勾選 1～3 項工作情境
3. 依所選情境動態顯示對應題組（每組 5 題，A～E 五點量尺）
4. 團隊與協作（固定 5 題）
5. 結果頁：雷達圖＋各能力面向分數與判讀文字

## 計分邏輯（官方公式）

```
各能力面向平均分 = 該面向所有已作答題目分數總和 ÷ 題目數
```

五大能力面向：AI技術應用、業務問題解決、AI應用與場景整合、數據識讀與治理、協作與領導

結果判讀：
- 4.0 以上：對相關概念具良好至深入理解，能獨立應用並進行延伸判斷
- 3.0～3.9：具基本理解，於部分情境下可應用，仍有精進空間
- 3.0 以下：理解有限或尚未建立完整概念，建議加強學習與練習

## 背景：與《AI產業人才認定指引》本文的關係

《AI產業人才認定指引(115年5月)(0525版)》是數位發展部數位產業署發布的上位政策指引，內容涵蓋：

- AI 人才三大類別：研究人才／開發人才／應用人才
- 11 項能力項目架構（AI素養、AI治理素養、文書/圖文/影像/音源應用、自動化應用、AI協作與開發、AI模型訓練、NLP/LLM/CV工程）
- 認證三大分類：素養類／工具類／專案類
- 官方另訂的「表5 AI產業人才能力自我評估量表」，以**證照累積張數＋課程受訓累積時數**評估5種能力類型，與本網頁的1～5分李克特量表計分方式不同，兩者不可互相替代或加總
- 人才職涯發展路徑、常見職稱範例、負責任使用 AI 的原則等

本網頁實作的「個人AI能力評估表單」，是指引中列為推薦學習資源的「AI產業人才賦能範本教材」附屬工具，對應指引「AI應用素養」與「AI工具應用」兩大能力類型，供個人快速盤點現況使用，並非指引本文定義的正式認證評估工具。
